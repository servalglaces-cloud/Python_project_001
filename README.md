# Projet Python 001 - Dessin du Logo Atlantic

Un projet Python simple et éducatif qui utilise la bibliothèque graphique **Turtle** pour dessiner le logo Atlantic de manière automatisée.

## 🚀 Fonctionnalités
- Dessin automatisé grâce au module `turtle` de Python.
- Code propre et structuré, idéal pour l'apprentissage des bases de la programmation.
- Excellent projet d'initiation pour les enfants et les débutants.
